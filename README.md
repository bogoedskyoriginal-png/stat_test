## Как открыть демо

1. Откройте файл `index.html` в браузере.
2. Нажмите на кнопку (⋮) на карточке ассистента и выберите «Статистика».
3. Переключайте период и метрики, чтобы увидеть адаптивные оси и всплывающие значения.
4. Нажмите «Скачать отчёт» для генерации CSV по выбранному периоду.

## Проверка User Stories и Use Cases

- User Story 1: по умолчанию выбран период «Последние 30 дней» и метрика «Количество запросов».
- User Story 2: кнопка «Выбрать период» открывает календарь, данные обновляются без перезагрузки.
- User Story 3: сайдбар метрик с подсветкой активной метрики; средние значения выводятся с дробной частью.
- User Story 4: выгрузка CSV включает все метрики за выбранный диапазон.
- User Story 5: логика 7-дневной доступности описана в комментариях; в демо все ассистенты старше 30 дней.
- Use Case 1–4: реализованы открытие модального окна, смена периода, смена метрики и скачивание отчёта.
- Use Case 6–7: диапазон автоматически обрезается до доступных дат, период ограничен 30 днями.
- Use Case 8: тултип отображает дату и значение для каждой точки.

## Файлы проекта

- `index.html` — основная страница с карточками и модальным окном статистики.
- `styles.css` — красноватая визуальная тема.
- `app.js` — логика интерфейса, графика и выгрузки CSV.
- `data/assistants.json` — исходные данные за период 11.02–12.03.2026.
- `data.js` — данные в формате, пригодном для работы в браузере.
